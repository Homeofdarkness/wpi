# Пример ввода moves_skipper

Это чистое состояние до первого хода: в нём нет кредита и накопленного
дефицита из предыдущих расчётов. Файлы проверены интеграционным тестом и
вставляются по порядку:

1. `01_economy_and_trade.txt` — в приглашение `ЭКОНОМИКА И ТОРГОВЛЯ`;
2. `02_industry.txt` — в `ПРОМЫШЛЕННОСТЬ`;
3. `03_industry_settings.toml` — в `TOML ПРОМЫШЛЕННОСТИ`;
4. `04_agriculture.txt` — в `СЕЛЬСКОЕ ХОЗЯЙСТВО`;
5. `05_government_control_people.txt` — в
   `ГОСУДАРСТВО, КОНТРОЛЬ И НАРОД`.

Ограждённые блоки можно вставлять вместе с строками из трёх обратных кавычек.
Они завершаются автоматически на закрывающей рамке. Чистый TOML без рамки
завершается двумя пустыми строками.

Можно копировать и только содержимое без рамок. Одиночные пустые строки внутри
такого текста сохраняются; после последней строки TOML нажмите Enter дважды.
