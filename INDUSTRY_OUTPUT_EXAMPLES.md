# Примеры промышленного вывода

Числа обычного хода получены реальным запуском с seed `20260718`.

## Обычный ход Эдема

Состояние ресурсов выровнено по столбцам и отделено от регистрации:

```text
СОСТОЯНИЕ ГРУПП

Лесное хозяйство [forestry]         | 1        | 526.9  | 0
Минеральная вода [mineral_water]    | 0        | 0      | 0
...

СОСТОЯНИЕ РЕСУРСОВ
Ресурс                                                | Склад          | Добыто | Дефицит
----------------------------------------------------- | -------------- | ------ | -------
Железо [iron]                                         | 7631.6 / 25000  | 1069.8 | 0

Уголь [coal]                                          | 4808.6 / 16000 | 885.5  | 0

```

```text

  Побочно: Шлак 6.5
```

В переносимой конфигурации сроки уже уменьшены:

```toml
[[production]]
id = "basic_building_materials"
name = "Базовые стройматериалы"
active = true
batches = 150.0
months = 33
inputs = { iron = 2.0, coal = 1.0, silicon = 0.5 }
outputs = { basic_building_materials = 2.5 }
byproducts = { slag = 0.4 }
```

## Групповая и индивидуальная добыча

```toml
[extraction.ferrous]
intensity = 80.0
priority = 2

[extraction.iron]
intensity = 100.0
priority = 1
```

Железо получает индивидуальное правило и вдвое больший относительный приоритет.
Групповой потенциал распределяется между остальными зарегистрированными
чёрными металлами. Абсолютная мощность, техника и работники в текстовом правиле
не задаются.

## Недостаток сырья

```text
ПРОИЗВОДСТВО ЗА ХОД
Железные детали [iron_parts]: план 5.0, выполнено 2.4 партий, осталось месяцев 0
  Взято: Железо 4.8
  Выпущено: Базовые стройматериалы 2.0
```

```toml
[[production]]
id = "iron_parts"
name = "Железные детали"
active = false
batches = 10.0
months = 0
inputs = { iron = 2.0 }
outputs = { basic_building_materials = 1.0 }
byproducts = {}
```

Небольшая разница с 2.5 партиями возникает из-за складской сохранности,
скомпонованной под длительность хода и применяемой до производства.

## Истечение правила

```text
Ход 1: выполнений=1, осталось=9 месяцев, статус=активно
Ход 2: выполнений=1, осталось=6 месяцев, статус=активно
Ход 3: выполнений=1, осталось=3 месяца, статус=активно
Ход 4: выполнений=1, осталось=0 месяцев, статус=завершено
```

Завершённое правило остаётся видимым. Для повторного запуска человек меняет
`active: true` и задаёт положительное число месяцев.

## Поправка ресурсов в бюджете

Профицит стройматериалов не меняет исходную строку инфраструктуры:

```text
╫ ─────────────────────РАСХОДЫ────────────────────── ╫
╫ Поправка расходов от ресурсов      ╫  -93.3 ед.вал ╫
╫ Общие расходы                      ╫ 1716.3 ед.вал ╫
╫════════════════════════════════════╫═══════════════╫
╫ ────────────ЭКОНОМИЧЕСКАЯ СТАБИЛЬНОСТЬ──────────── ╫
╫ Стабильность до хода               ╫        100.0% ╫
╫ Поправка государственного аппарата ╫     +0.0 п.п. ╫
╫ Поправка эффектов                  ╫     +0.0 п.п. ╫
╫ Стабильность после хода            ╫        100.0% ╫
```

Это отдельная рассчитанная стата отчёта; она входит в общие расходы только при
сведении хода.

## Эффекты на произвольные статы

Команда `uv run python create_basic_country.py` только создаёт страну:

```text
ЭФФЕКТЫ ПРОМЫШЛЕННОСТИ
freshwater_society:
  contentment                : ожидает расчёта хода
  food_diversity             : ожидает расчёта хода
  population_epidemic_chance : ожидает расчёта хода
```

Команда `uv run python create_basic_country.py --turns 1 --seed 1` реально
рассчитывает ход. Проверенный пример Эдема содержит четыре эффекта и семь
отдельных применений. При отсутствии дефицита транспортные и социальные штрафы
остаются нулевыми:

```text
Казна после хода: 358.382
Прирост: 90119.2
Торговая прибыль: 98.989
Обеспеченность едой: 107.6

ЭФФЕКТЫ ПРОМЫШЛЕННОСТИ
freshwater_population_growth:
  population_growth          : 67360.0 -> 67360.0 (+0.0)
construction_infrastructure_expenses:
  infrastructure_expenses    :    466.4 ->    373.1 (-93.3)
hydrocarbons_transport:
  logistic                   :     27.0 ->     27.0 (+0.0)
  trade_efficiency           :     98.0 ->     98.0 (+0.0)
freshwater_society:
  contentment                :     89.0 ->     89.0 (+0.0)
  food_diversity             :     96.7 ->     96.7 (+0.0)
  population_epidemic_chance :      0.8 ->      0.8 (+0.0)
```

Отдельная конфигурация произвольного ресурса `reinforced_glass` действительно
влияет на обычные статы, производную эффективность и вероятность аварии:

```text
infrastructure_expenses    :  50.000 ->  40.000 (-10.000)
logistic                   :  60.000 ->  64.133 ( +4.133)
civil_efficiency           :  99.975 -> 106.861 ( +6.886)
industrial_accident_chance :   2.151 ->   1.657 ( -0.494)
```

Исходный пример находится в `test_files/custom_resource_industry_example.toml`.
Каждая строка получена из `country.industry.last_effects` после полного хода;
формат `до -> после (изменение)` помогает проверить действие формулы.
